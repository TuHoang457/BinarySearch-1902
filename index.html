Left Pointer (L) Vị trí bắt đầu vùng tìm kiếm hiện tại.
Mid Pointer (M) Phần tử ở giữa dùng để so sánh với Target.
Right Pointer (R) Vị trí kết thúc vùng tìm kiếm hiện tại.
Found Element Vị trí tìm thấy giá trị Target.
Normal Element Các phần tử chưa được xét hoặc nằm ngoài vùng tìm kiếm.

Pseudo-code

left = 0, right = n - 1
while (left <= right):
  mid = floor((left+right)/2)
  if array[mid] == target:
    return mid // Found!
  if array[mid] < target:
    left = mid + 1
  else:
    right = mid - 1
return -1 // Not Found
